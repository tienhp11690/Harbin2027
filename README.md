## 🌐 File Web Trực Quan Hóa (Interactive HTML)

Toàn bộ lịch trình, bản đồ di chuyển bằng tàu cao tốc/xe buýt, hướng dẫn bay drone -30°C, giáo trình học trượt tuyết và bảng dự toán chi phí đã được đóng gói thành file **`index.html`**.

### Cách đưa lên GitHub & GitHub Pages để chia sẻ:
1. Tạo một repository mới trên GitHub (ví dụ: `dongbac-snow-trip`).
2. Push file `index.html` và `README.md` lên repository:
   ```bash
   git init
   git add .
   git commit -m "Lịch trình Đông Bắc Trung Quốc 12N11Đ"
   git branch -M main
   git remote add origin https://github.com/<username>/<repo-name>.git
   git push -u origin main
   ```
3. Vào repository trên GitHub ➔ **Settings** ➔ **Pages** ➔ Chọn branch `main` và thư mục `/ (root)` ➔ Bấm **Save**.
4. Sau 1 phút, trang web sẽ online tại: `https://<username>.github.io/<repo-name>/`
