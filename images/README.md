## ⚡ 3. Cơ Chế Tự Động Resize & Tối Ưu Hiển Thị

Bạn không cần lo lắng về việc ảnh tải về quá to (ảnh 4K, ảnh chụp máy 48MP dung lượng 5-10MB):

1. **Tự Động Căn Khung Trên Web (CSS Responsive Engine):**
   - Web app được thiết lập `object-fit: cover` và `aspect-ratio` tự động. Bất kể bạn tải ảnh tỷ lệ ngang (16:9, 4:3), dọc (9:16) hay vuông (1:1), hệ thống sẽ **tự động cắt cúp và căn giữa vào khung thẻ một cách cân đối và tinh tế**, không bao giờ bị méo hình hay vỡ giao diện.
2. **Công Cụ Tối Ưu Hóa 1-Click (`optimize-images.bat`):**
   - Sau khi bạn bỏ ảnh mới vào các thư mục trên, hãy **click đúp vào file `optimize-images.bat`** tại thư mục gốc của dự án.
   - Script chạy trực tiếp bằng PowerShell Windows (không cần cài thêm phần mềm nào), sẽ tự động:
     - Quét toàn bộ ảnh trong các thư mục con.
     - Tự động nén và resize về kích thước chuẩn (Max 800px cho Concept/Outfit, Max 1200px cho Banner hoạt động).
     - Giảm 70-90% dung lượng file (từ 5MB xuống ~100-200KB) nhưng mắt thường hoàn toàn không nhận thấy sự suy giảm độ sắc nét.
3. **Cơ Chế Dự Phòng (Fallback) 100% Không Lỗi:**
   - Nếu bạn chưa kịp bỏ ảnh vào folder local, web app sẽ tự động hiển thị ảnh chất lượng cao từ CDN online dự phòng qua lệnh `onerror`. Trang web sẽ luôn hiển thị lung linh trong mọi tình huống!
